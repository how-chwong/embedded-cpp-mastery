# 第1章：圣杯：张量（Tensors）与自动梯度求除（Autograd）（PyTorch篇 Tensors）

在 C# 或者是日常开发中，当我们面对数据集合，经常会写出如下代码：
```csharp
// C# 二维平面物理矩阵定义
double[,] matrix = new double[3, 4];
```
这些多维数组虽然能很好地在单机 CPU 暂存数据，但一旦用于深度学习：它们不支持瞬间并行传给显卡、它们更不知道每一层计算该如何去求导、算偏导。

在 PyTorch 中，用来构筑整个宇宙数据的唯一实体就是 **`Tensor` (张量)**。本章我们将重点揭秘这个神奇的数据结构，以及让高维微积分可以被计算引擎自动化解析求导的绝对法宝 —— **`Autograd` 自动梯度系统**。

---

## 1. 什么是张量（Tensor）？

简单一句话理解：**张量就是可以并行在 GPU 飞驰运行、并支持高精度自动微积分梯度（Gradient）计算的高级超多维数组。**

根据张量的**“秩（也即维度阶数 Dimensions / Axes）”**不同，我们给它们起我们熟悉的俗名：

```
   [ Scalar ]  ------> 0D Tensor (一个单纯的不带箭头的标量数字，如: 5)
   [ Vector ]  ------> 1D Tensor (一条单排数字向量，如: [1, 2, 3])
   [ Matrix ]  ------> 2D Tensor (具有长宽格式的二维平面矩阵)
   [ Cube ]    ------> 3D Tensor (具有长、宽、深的三维体，如: RGB 彩色图片，包含了长, 宽, 3个颜色通道)
   [ Batch ]   ------> 4D Tensor (一个成捆、大批量的数据组，如: 一批 32 张彩色照片放在一起)
```

---

## 2. 张量物理大本营：核心操作实操

下面，我们在本地沙盒中创建、操作并改变张量的形态，这是每一天在 PyTorch 编程中不可或缺的肌肉练习：

### 1. 新建 `tensor_basics.py`
创建文件并研读以下强类型注释代码：

```python
import torch
import numpy as np

print("🧪 --- 开启高维度张量基础练习 --- 🧪\n")

# A. 4 种最经典的张量瞬间创建法
# 1. 直接从原始 Python 列表包装产生 (类似于 C# 数组转换成对象型)
t1 = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
print(f"1. 手造 2D 张量:\n{t1}\n形状 .shape: {t1.shape}\n数据类型 .dtype: {t1.dtype}\n")

# 2. 创建所有元素全为 0 的指定规格超多维张量 (对标 C# new double[长, 宽])
t_zeros = torch.zeros(3, 4) # 3 行 4 列
print(f"2. 全零 3x4 张量:\n{t_zeros}\n")

# 3. 创建带有随机正态分布的随机初始化矩阵形式 (深度学习在最开始需要随机分配系数)
t_rand = torch.randn(2, 3) # 2 行 3 列的随机浮点张量
print(f"3. 随机正态分布 2x3 张量:\n{t_rand}\n")

# 4. 【大桥梁】：与 Python 最庞大、最统治级的传统 CPU 矩阵库 NumPy 进行无摩擦零开销互操作！
numpy_array = np.array([10.0, 20.0, 30.0])
# 它们在底层共享同一块系统内存！根本没有重复拷贝的高物理 I/O 开销！
t_from_np = torch.from_numpy(numpy_array) 
print(f"4. NumPy 直接变身 Torch Tensor:\n{t_from_np}\n")

# B. 【深度学习头号报错杀手平退】：改变张量的维度形态 (Reshape)
# 经常地，你在网络里要把 32x28x28 这样的多维图像，在一秒内彻底拉平为单一维度的一维 32x784 向量。
# 在 PyTorch 中，使用内置最经典的 .view() 或者是 .reshape() 方法！
t2 = torch.arange(12) # 生成 0 到 11 的 12 个一维数字向量
print(f"原本一维排列: {t2}")

# 将 12 元素瞬间变身 3 行 4 列的二维面片
# 技巧：参数填入 -1 代表“这一部分的维度长度我懒得手算，请 PyTorch 自动根据总长折算！”
t2_reshaped = t2.view(3, 4) 
print(f"一变三行四列 view(3, 4):\n{t2_reshaped}")
```

运行程序：`python tensor_basics.py`，你将彻底习惯与多维张量的近距离对话。

## 3. Autograd 自动求导：深度学习之所以成气候的“圣杯”

在早期的 AI 工程中，为了让一具有成千上万层隐蔽网络的庞大系统能够利用误差，求导，并在反向传播中更新这些几亿个错综复杂的参数，科学家需要手算复杂的微积分偏导方程，最后通过艰难地编写 C++ 去对每一个变量乘上微弱的差值。这种做法在网络结构发生改变时，整条反解代码需要推倒重写！

PyTorch 引入了极其前卫和震撼的 **Autograd（自动求导）系统**：
- 只要一个 Tensor 的关键参数被标上了 **`requires_grad=True`**，PyTorch 的后台计算引擎（CPython 底层 C++ Graph 跟踪器）就会默默记住：“**这是我们需要在后面求导、更新它的待训练参数！**”
- 之后你对该 Tensor 做出的所有数学运行（如加、减、乘、指数、平方），都会在后台伴随着你的进程，**自动生成一副相互级联的、数学化的“动态计算图 (Dynamic Computation Graph)”**。
- 一旦计算到达最终的出口（如误差损失 `Loss` 汇总后），你只需对这个单一 `Loss` 调用一行命令：
  $$\text{Loss.backward()}$$
- 这一声号令，会让后台的动态计算图瞬息**从头相反递归拆行**，自动在百分之一毫秒内，在显存深处计算并填满每一个 requires_grad 变量它当前的精密微积分偏导梯度值——这便是大名鼎鼎的 **误差反向传播 (Backpropagation)**！

### 🛠️ 实战感受：一行代码的反向微积分求导

假设我们在数学上有一个最简单的抛物钱方程：
$$y = 3x^2 + 5x \quad \text{其中 } x = 2.0$$

在求复合导数（微积分）中，根据高中数学我们可知，其 $y$ 对 $x$ 的导数方程为：
$$\frac{dy}{dx} = 6x + 5$$
代入 $x=2.0$，可知此时其梯度值应当在数学上完美等于 $6 \times 2 + 5 = 17.0$。

让我们看一看 PyTorch 它是如何在几行代码内，自动化推导出这个梯度值的：

```python
# 新建演示 `torch_grad.py`
import torch

# 1. 声明自变量 x 为 2.0，并且特别标注：【我们需要追踪它的梯度！】
x = torch.tensor(2.0, requires_grad=True)

# 2. 用普通代码写出我们的方程逻辑。
# PyTorch 看完这行，已在后台自动建好了动态求导链路图
y = 3 * (x ** 2) + 5 * x

print(f"自变量 x 的值: {x}")
print(f"因变量 y 计算出来的值: {y}") # 3*(2^2) + 5*2 = 22

# 3. 影子一击号令：自动反向求微积分导数！
y.backward()

# 4. 在屏幕上输出自变量 x 的身上被自动算好并注入的梯度（导数）
print(f"🔮 通过 Autograd 自动反向求导后，x 当前的偏导梯度值 (.grad) 为: {x.grad}") # 17.0!
```

#### 控制台呼啸的输出反馈：
```text
自变量 x 的值: 2.0
因变量 y 计算出来的值: 22.0
🔮 通过 Autograd 自动反向求导后，x 当前的偏导梯度值 (.grad) 为: 17.0
```

你看到了吗？
PyTorch 在运行时，通过追溯运算链，不需要任何硬编码的导数公式，就自己“无声地求出了微积分偏导数”！
这正是神经网络能够自发地、通过一次又一次寻找反负方向去摸缩调整上亿个权重参数、从而达到让人类惊愕的智能精度的核心密码，也是 PyTorch 征服全球科研大师的终极圣杯。
