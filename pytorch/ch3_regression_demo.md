## 1. 案例目标与开发环境配置

我们要预测的房价，其背后真实存在的客观大自然规律（我们假造的规律，AI 一开始对此一无所知）为：
$$\text{价格 (万元)} = 2.5 \times \text{面积 (平方米)} + 50.0 + \text{小范围物理白噪声扰动}$$

## 2. 🛠️ 动手狂飚：完整房价预测实操 `house_regression.py`

新建该 Python 物理脚本，完全粘贴以下具备高对比强注释的代码，并在控制台中开始你的 AI 训练：

```python
import torch
import torch.nn as nn
import numpy as np

print("🏡 --- 启动 PyTorch 房价线性回归预测神经网络实验 --- 🏡\n")

# ==========================================
# 1. 制造高拟真物理训练数据散点 (对标 C# Data Access)
# ==========================================
# 我们随机制造 100 套房屋面积的数据，分布在 50~150 平米之间
np.random.seed(42)  # 设置随机数种子以便结果能复现
X_raw = np.random.uniform(50, 150, (100, 1))

# 根据大自然物理公式: 价格 = 2.5 * 面积 + 50.0 + 几万元的浮动误差扰动 (白噪声)
y_raw = 2.5 * X_raw + 50.0 + np.random.normal(0, 10, (100, 1))

# 将 numpy 数组高秒转换为 PyTorch CUDA-ready 的浮点 FloatTensor张量！
# 深度学习网络中，参数的数据格式默认首选 32 位浮点单精度 (float32)！
X_train = torch.FloatTensor(X_raw)
y_train = torch.FloatTensor(y_raw)

print(f"数据生成完成！样例: 第一套房面积 {X_raw[0][0]:.1f} 平米 -> 实际真实售价: {y_raw[0][0]:.1f} 万元\n")


# ==========================================
# 2. 定义我们的极简极强神经网络骨架 (nn.Module 对标)
# ==========================================
class HousePriceNet(nn.Module):
    def __init__(self):
        super().__init__()
        # 因为我们的预测输入只有 [面积] 这一维自变量，输出也只有单一 [价格]
        # 所以我们使用带有一个输入、一个输出的 nn.Linear 物理映射层
        self.predictor = nn.Linear(1, 1)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.predictor(x)

# 实例化模型
model = HousePriceNet()


# ==========================================
# 3. 指定考官 Loss 损失评估和优化改进系数的导师 Optimizer
# ==========================================
# 选用经典的均方误差 L2 Loss 作为考量器（MSELoss，最适合回归评估）
criterion = nn.MSELoss()

# 选用最常好用的经典优化器 Adam 算法
# model.parameters() 会将网络中我们刚才 Linear 包含的 requires_grad=True 的 w 和 b 自发绑定
# lr (learning rate) 学习率：类似于导师每一步纠偏的精细步伐力度，0.1~0.5 对于此回归极佳
optimizer = torch.optim.Adam(model.parameters(), lr=0.3)


# ==========================================
# 4. 进入最带劲的：工业级 5 步训练大循环！
# ==========================================
# 我们让模型循环学习 800 轮 (Epochs)
print("🏋️‍♂️ 神经网络脑正在飞速调整突触、进行自我学习纠偏中...")

for epoch in range(1, 801):
    # 【5步大循环高能狂飙！】
    # 第 1 步：模型在当前权重下进行房价预测计算
    predictions = model(X_train)
    
    # 第 2 步：比对预测房价与实际真实售价格，算出当期误差
    loss = criterion(predictions, y_train)
    
    # 第 3 步：强力清空多余的历史遗留梯度偏导极其残留数据
    optimizer.zero_grad()
    
    # 第 4 步：动态自动反向求偏导微积分
    loss.backward()
    
    # 第 5 步：导师大刀阔斧修正 w (权重斜率) 与 b (偏移偏差值)
    optimizer.step()

    # 每过 100 轮，我们在屏幕上反馈汇报一下脑力进度的自新水平
    if epoch % 100 == 0:
        # 特别贴士：在读取数值做统计、不想破坏动态图偏导时，
        # 在 PyTorch 中推荐使用 `with torch.no_grad():` 上下文拦截（这能大大省下 CPU/GPU 开销！）
        with torch.no_grad():
            # 拿到我们隐藏在 Linear 内部的真实 w 和 b 权重系数
            w = model.predictor.weight[0][0].item()
            b = model.predictor.bias[0].item()
            print(f"  ├─ 轮次 [Epoch {epoch:03d}/800] 评估当前误差 Loss: {loss.item():.2f} | 此时学到的系数: w = {w:.3f}, b = {b:.3f}")

print("\n🎉 训练演练收官！AI 脑进化调试功德圆满。")


# ==========================================
# 5. 上线接收大考核：新房智能模拟报价！
# ==========================================
print("\n🔮 --- 系统上线运行 测试未知房价智能诊断 --- 🔮")

# 假设我们在大区中，最新建起了三套面积分别为 70 P㎡、115 P㎡、140 P㎡ 的新房
new_houses = torch.FloatTensor([[70.0], [115.0], [140.0]])

# 切换为模型“评估/运用模式”，关掉需要计算梯度的后台动态引擎（极其省资源、规范做法！）
model.eval()

with torch.no_grad():
    predictions_new = model(new_houses)

# 输出大平预测：
for i, area in enumerate([70, 115, 140]):
    predicted_val = predictions_new[i][0].item()
    
    # 让我们看看，与真实物理规律价格（2.5 * Area + 50.0）相对比，AI 到底有多神准！
    baseline_val = 2.5 * area + 50.0
    print(f"  🏢 新房面积: {area}㎡ | AI 测算合理估价: {predicted_val:.1f} 万元 (基准底线真实值: {baseline_val:.1f} 万)")
```
